# vek.h

Dynamically resizable vectors in C.

> [!WARNING]
> The design of the library is not finished and may be a subject to change.

## Usage

In **one** `.c` file, define `VEK_IMPLEMENTATION` before including `vek.h`:

```c
#define VEK_IMPLEMENTATION
#include "vek.h"
```

## Quick Start

Check [example.c](./example.c)

```console
$ make
$ ./example
```
